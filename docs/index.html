Shrink

Get back the space WSL and Docker keep

WSL and Docker store each Linux system in one virtual disk file. The file grows as Linux needs space but never shrinks when you delete things. Disk Space Analyzer shows how much of each file is really in use, cleans caches inside it, and compacts the file.

Accurate

Numbers you can trust

Disk analyzers often count some space twice or miss it entirely. Disk Space Analyzer handles the cases that trip others up.

Nothing counted twice

Junctions and symbolic links aren't followed, and folders that packaged apps like Claude redirect are counted once.

Cloud files count as zero

OneDrive files that are online-only take no space on your PC, so they aren't added to the total. Their size is shown separately.

Real size on disk

Compressed and sparse files count the space they actually use, not the size they report.

Long paths work

Folders nested deeper than Windows' old 260-character limit are scanned, copied and checked like any other.

Moves you can resume

Stop a copy at any point. Starting again skips the files that are already done, and any file that doesn't match is copied again.

Light and dark

Follows your Windows theme and accent color, or set it yourself.
